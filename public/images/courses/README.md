# Course Images Directory (`public/images/courses/`)

Place all course card and course detail header images in this folder.

### Recommended Dimensions:
- **Aspect Ratio:** 4:3 (~800x600px or ~1200x900px)
- **Format:** `.jpg`, `.jpeg`, `.webp`, or `.png`
- **Guidelines:** Clean, high-resolution aesthetic clinic or beauty spa treatment images without logos/watermarks.
