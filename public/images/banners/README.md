# Banner Images Directory (`public/images/banners/` & `public/images/`)

Place all homepage hero and section banner images in this folder or in `public/images/`.

### Recommended Dimensions:
- **Aspect Ratio:** 16:9 or Landscape (~1920x1080px or ~1600x900px)
- **Format:** `.jpg`, `.jpeg`, `.webp`, or `.png`

---

### Banner Image Names:

1. **`hero_lashes.jpg`**
   - **Section:** Homepage Hero Slide 1 (Lash Masterclasses)
   - **Description:** Professional high-end lash extension / eye beauty treatment image.

2. **`hero_brows.jpg`**
   - **Section:** Homepage Hero Slide 2 (Brow & Lamination)
   - **Description:** Precision eyebrow styling, microblading or lamination close-up image.

3. **`hero_aesthetics.jpg`**
   - **Section:** Homepage Hero Slide 3 & About page (Clinical Aesthetics)
   - **Description:** Premium clinical aesthetics / facial treatment image.

4. **`og-share.jpg`**
   - **Section:** Social Media Share Card (Open Graph / Twitter preview)
   - **Recommended Size:** Exact 1200x630px.
